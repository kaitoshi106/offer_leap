# Glossary

| Term           | Meaning                                                                                |
| -------------- | -------------------------------------------------------------------------------------- |
| CV / Resume    | Candidate document uploaded as PDF, DOCX or image                                      |
| JD             | Job description pasted by the user                                                     |
| Onboarding     | Mandatory profile completion after sign-up (industry, experience, location…)           |
| Profile        | Structured candidate data used by every AI feature                                     |
| Industry       | Entry of the industry taxonomy, stored by `code`, labelled in vi/en                    |
| Province       | Vietnamese province/city (post-2025 administrative units), stored by `code`            |
| Level          | Seniority: intern, fresher, junior, middle, senior, lead, manager                      |
| Match score    | 0–100 fit between a CV and a JD with a rubric breakdown                                |
| Mock interview | AI-led interview session for a given JD, scored per answer                             |
| Root admin     | The single system-provisioned admin; invites general admins; password managed via env  |
| General admin  | Admin who joined via invitation from root                                              |
| Invitation     | Single-use, expiring token sent by email that lets someone register as a general admin |
